# 🎬 RSVP Movies – Basic SQL Project

## 📌 Project Overview

This project demonstrates the practical application of SQL using a movie database. It focuses on managing movie-related information and performing basic data analysis using MySQL.

The project explores movie details, directors, ratings, budgets, and revenue to generate meaningful insights through SQL queries.

It is designed for beginners who want to strengthen their SQL fundamentals and understand how relational databases work.

## 🎯 Project Objectives

- Create and manage a relational database.
- Store movie, director, and rating information.
- Understand Primary Keys and Foreign Keys.
- Perform data retrieval using SELECT statements.
- Filter records using WHERE conditions.
- Apply JOIN operations across multiple tables.
- Perform aggregations using AVG() and GROUP BY.
- Analyze movie revenue, budget, and profit.

## 🛠️ Technologies Used

- **Database:** MySQL
- **Language:** SQL
- **Concepts:** DDL, DML, SELECT, WHERE, ORDER BY, LIMIT, JOIN, GROUP BY, Aggregate Functions

## 🗂️ Database Structure

The project contains four tables:

| Table Name | Description |
|---|---|
| Movies | Stores movie details, genre, language, budget, and revenue |
| Directors | Stores director information |
| Movie_Director | Connects movies with their directors |
| Ratings | Stores movie ratings |

## 📊 SQL Analysis Performed

The project includes the following queries:

1. List all movies released after 2017.
2. Find the movie with the highest revenue.
3. Display movies with a rating greater than 7.
4. Retrieve directors and their respective movies using JOIN.
5. Calculate movie profit using Revenue - Budget.
6. Calculate average movie ratings by genre.
7. Retrieve the top three movies based on ratings.
